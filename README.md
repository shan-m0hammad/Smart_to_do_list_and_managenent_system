## 📌 Project Overview

The **Smart To-Do List** is a simple task management system designed to
help users organize and manage their daily tasks efficiently.

The system allows users to create, view, update, delete, and manage tasks
in an organized manner. The project demonstrates the practical
application of programming and data structure concepts.

---

## 🎯 Problem Statement

Managing multiple academic and daily tasks can become difficult when
tasks are not properly organized. Users may forget important tasks,
deadlines, or pending work.

The Smart To-Do List provides a simple solution for managing tasks in one
place and keeping track of completed and pending activities.

---

## 🎯 Objectives

- To provide a simple task management system.
- To add and store tasks efficiently.
- To display pending and completed tasks.
- To update existing tasks.
- To delete unnecessary tasks.
- To mark tasks as completed.
- To apply Data Structures and programming concepts in a practical
  project.
